# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub: open the
[Security tab](https://github.com/useblacksmith/js-test-plugins/security) of
this repository and choose "Report a vulnerability". Do not open a public issue
or pull request for it.

Include the package and version, what an attacker can do, and the smallest
project or steps that show it.

## Supported versions

Fixes go into the latest release of each package (`@useblacksmith/vitest`,
`@useblacksmith/mocha`, `@useblacksmith/jest`).
